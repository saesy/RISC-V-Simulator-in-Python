# RISC-V-Simulator-in-Python
RISC-V Simulator with 5-stage pipelining and 2-bit branch prediction built over the course of CS4200 university class.

# Usage

Add file called hex_inst.txt to where your directory can pull from directly. Instructions should be listed in hexadecimal, without leading "0x" and be listed as one instruction per line. Program terminates once next line is empty (is None) or 50 million cycles are reached (for infinite loop protection).
