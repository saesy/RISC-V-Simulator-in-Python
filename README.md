# RISC-V-Simulator-in-Python
RISC-V Simulator with 5-stage pipelining and 2-bit branch prediction built over the course of CS4200 university class.

# Usage

Add file called hex_inst.txt to where your directory can pull from directly. Instructions should be listed as one per line. Program terminates once next line is empty (is None).
